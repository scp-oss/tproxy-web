WireGuard для Telegram (звонки на Android и iPhone)

Профиль для приложения WireGuard на телефоне: в туннель идёт только Telegram — сообщения, звонки, видео; остальной интернет телефона как обычно. Звонки работают, если задан внешний узел (блок выше). Для своей сети: адрес в профиле — локальный IP.

Звонки дома через роутер Keenetic
Роутер сам заворачивает трафик Telegram всех устройств сети в туннель до панели, а панель — в выход за границу. На телефонах ничего настраивать не нужно, звонки работают и на Android. Нужны: внешний узел и включённый модуль WireGuard (блоки выше).
  1. Профиль для роутера. Здесь, в блоке WireGuard: имя «Keenetic» → «Добавить вручную» → «Скачать .conf».
  2. Компонент WireGuard. В веб-интерфейсе Keenetic: Управление → Общие настройки → Изменить набор компонентов, отметьте «WireGuard VPN» и установите. Роутер перезагрузится. Если компонент уже есть — пропустите.
  3. Подключение. Интернет → Другие подключения, раздел «WireGuard» → «Загрузить из файла» → выберите .conf. Откройте появившееся подключение, снимите «Использовать для выхода в интернет», сохраните и включите переключатель подключения. Через несколько секунд статус — «Подключено».
  4. Маршруты до сетей Telegram. Сетевые правила → Маршрутизация → Добавить маршрут — для каждой строки таблицы: «Тип маршрута» — Маршрут до сети, «Адрес сети назначения» и «Маска» — из таблицы, «Адрес шлюза» — пусто, «Интерфейс» — подключение WireGuard из шага 3, галочка «Добавлять автоматически». Сохранить.

  5. Проверка. Выключите прокси в Telegram на телефоне и позвоните. На странице подключения WireGuard в Keenetic должны расти счётчики переданных данных.
Отменить: удалите эти маршруты в Маршрутизация и выключите подключение WireGuard. Остальной интернет сети этот способ не трогает: в туннель идут только сети Telegram.
